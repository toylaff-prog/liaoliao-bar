# 聊聊BAR 3D 多人房間版

單一網頁，不需要安裝或建置。用 Three.js 繪製「聊聊BAR」親師交流空間，含 7 位 Q 版人物與 6 種小遊戲，
可以建立房間、讓大家用手機或電腦一起玩。線上版：https://toylaff-prog.github.io/liaoliao-bar/

## 怎麼一起玩
1. 房主打開網頁，按下方「多人房間」→「建立房間」，會得到 4 位代碼、邀請連結和 QR code。可以先設定「房間密碼」（選填）。
2. 其他人掃 QR code、打開邀請連結，或輸入代碼加入（有設密碼的要另外輸入密碼）。每個人會自動分到一個還沒人用的人物，也可以在「多人房間」視窗改選。
3. 沒人選的人物，遊戲時由電腦代打。
4. 房主負責選場景和遊戲；輪到你的人物時，才能按遊戲按鈕。每個人可以移動、改姿勢、改名自己的人物，家具擺設大家都看得到。
5. 房主可以在「多人房間」視窗把人移出房間；被移出的人在這個房間無法再加入。

## 連線方式與限制
- 連線使用 WebRTC（點對點），房主的瀏覽器就是「伺服器」：房主離開，房間就會關閉；不會保存任何遊戲資料。
- 房主的網頁在手機上會盡量保持螢幕不休眠；房主如果切到別的程式或關螢幕，大家的畫面會停住。建議房主用電腦，或讓手機保持亮著。
- 訪客斷線時會自動重新連線（最多約 1 分鐘），成功後會回到原本的座位。房主離開或關閉網頁時，訪客會馬上看到提示。
- 目前沒有「房主交接」：房主離開，房間就結束。
- 預設透過 PeerJS 的免費公開服務幫大家互相找到對方（內建免費 STUN／TURN），這項服務不保證永遠可用。
- 少數網路（部分學校、公司防火牆）會擋住 WebRTC，這時加入會失敗並顯示原因。可以改用手機行動網路，或在 config.js 加入自己的 TURN／PeerJS server。
- 「同一台裝置的分頁（測試）」模式只能在同一台電腦、同一個瀏覽器開多個分頁測試。
- 大家輸入的暱稱，房間裡所有人都看得到，請不要填真實姓名或個人資料。

## 手機與效能
- 手機（或核心數很少的裝置）會自動使用「省電畫質」（關閉陰影、降低解析度）；網址加上 ?lite=0 可以強制用完整畫質，?lite=1 強制省電。
- 畫面太卡（平均低於約 24 FPS）時，會自動切換成省電畫質。
- 可以「加到主畫面」當成 App 使用；函式庫會快取，第二次開啟更快。

## 放上 GitHub Pages
1. 在 GitHub 新增一個 repository（免費帳號請選 Public，Pages 才能使用）。
2. 把這個資料夾裡的所有檔案（含 lib 資料夾）上傳到 repository 根目錄。
3. Settings → Pages，Source 選 Deploy from a branch，Branch 選 main，資料夾選 /(root)，按 Save。
4. 等 1～2 分鐘，網址會是 https://<帳號>.github.io/<repository 名稱>/

## 自動測試
需要 Node.js。在專案資料夾執行：

```
npm i playwright peer
npx playwright install chromium
node tests/e2e.mjs
```

測試會啟動本機的靜態網站和 PeerJS 伺服器，用兩個瀏覽器分頁（房主＋訪客）檢查：加入、座位、密碼、踢人、斷線重連，以及 6 個遊戲的多人同步。
沒有顯示卡的機器（用軟體繪圖）大約要跑 10 分鐘，有顯示卡的電腦會快很多。
